# MVP Scope

| Priority Tier | Features |
|---|---|
| MUST HAVE | Fixed-total-time assessment engine with accuracy+speed scoring; Competitive Rating with basic decay; GitHub-style contribution heatmap (cheap, high visual payoff). |
| SHOULD HAVE | NotebookLM-style text summary cards; 2D skill graph as the safe baseline. |
| NICE TO HAVE | Audio overview generation (TTS); department-scoped leaderboard. |
| FUTURE SCOPE (out of hackathon scope) | 3D skill visualization as primary/default view (ship 2D first; add 3D only if time remains); video overview generation; cross-department public leaderboard; advanced anti-gaming detection for rating system. |
