# Project Context

Source: internal SIH research document.

## Problem Context (MoSPI / DIID)
- Nirdesha addresses the MoSPI Data Informatics & Innovation Division problem: identify competency gaps for officials, personalize training via iGOT-linked learning pathways, and support AI-generated MCQ/quiz flows from provided learning material. [B]

## iGOT Karmayogi Facts
- iGOT Karmayogi is run by Karmayogi Bharat, a government-owned SPV. [B]
- Platform scale includes 2,400+ courses and supports 16 languages for learning content delivery. [B]
- Intended user base is government officials; not a public open-learning portal for all users. [B]
- There is no publicly documented third-party authenticated iGOT API for direct external integration; official access path is unknown and likely restricted. [E]

## NSSTA Facts
- NSSTA (National Statistical Systems Training Academy) is MoSPI’s training academy located in Greater Noida. [B]
- Training programmes are approved through TPAC (Training Programme Approval Committee). [B]
- Publicly visible programme communication is primarily through training-calendar documents/PDFs, not a public API integration surface. [E]
