## 🏛️ Executive Summary

**निर्देश (Nirdesha)** is an enterprise-grade competency intelligence, continuous diagnostic assessment, and personalized learning guidance platform designed for the **Ministry of Statistics and Programme Implementation (MoSPI)**, Government of India. 

Addressing the critical capacity-building mandate of the **Subordinate Statistical Service (SSS)** and **Indian Statistical Service (ISS)** cadres, Nirdesha transitions traditional civil service training from periodic classroom attendance into an **auditable, real-time, data-driven competency ecosystem**.

Nirdesha bridges national training frameworks—specifically **Mission Karmayogi (iGOT Karmayogi)** and the **National Statistical Systems Training Academy (NSSTA)**—with state-of-the-art **Assistive Artificial Intelligence (Google Gemini)** and a **Deterministic Evaluation Engine**.

### 1. The Separation of Concerns
* **The AI Layer is strictly Assistive & Probabilistic:** It provides tailored explanations, guides navigation, renders LaTeX formula proofs, and drafts contextual quiz questions. **It is never permitted to write directly to official cadre records or alter competency scores unchecked.**
* **The Core Engine is 100% Deterministic & Auditable:** Official competency scores, promotion readiness indices, disciplinary actions, and Elo ratings are governed by explicit, rule-based mathematical functions and stored with audit logs.

## 🚀 Detailed Feature Walkthrough

### 👨‍💼 Trainee & Officer Learning Portal (`/dashboard`)
* **52-Week Learning Heatmap (364 Days):** Full-width, GitHub-style consistency grid tracking daily training activity, timed evaluations, and CAPI field simulation tasks.
* **14-Day Circular Streak & Milestone Wheel:** Precision SVG progress ring coupled with a 365-day 3D cylindrical date wheel picker for setting realistic annual learning goals.
* **Competitive Per-Domain Skill Ratings (Elo Algorithm):**
  * Evaluates accuracy percentage, time budget efficiency, and question difficulty ($K=24$, starting baseline 1200).
  * Strict accuracy floor ($<40\%$ prevents speed-gaming).
  * Inactivity decay safeguards and transparent explanation cards.
* **Dual Visualization: 2D Radar & 3D Celestial Topology:**
  * **2D Skill Radar:** Clear target vs. current proficiency polygon.
  * **3D Scientific Competency Map:** Built with Three.js, featuring graphite-core PBR nodes, glowing telemetry filaments, travelling photon energy pulses, depth attenuation, and hovering reticles.
* **Personal AI Study Mentor (Powered by Google Gemini):**
  * **Exhaustive Mathematics & Proofs:** Full LaTeX rendering via KaTeX with custom visual fraction and formula fallbacks ($Horvitz\text{-}Thompson$, $Laspeyres$, $Taylor\text{ }Series$).
  * **11 Scheduled Languages:** Seamless translation in native scripts (Hindi, Odia, Bengali, Marathi, Gujarati, Tamil, Telugu, Kannada, Malayalam, Punjabi, English).
  * **ChatGPT-Style Past Conversations Drawer:** Preserves recent chat sessions with instant recall, title extractions, and prompt chips.
  * **Response Personalization Studio:** Control format (Step-by-step, Table, Bullet points), depth (Concise to Comprehensive), and Tone (Mentor, Administrative, Scoring).
  * **Session Notes & Multi-Format Export:** 1-click conversion of chat sessions into formatted study notes with exports to **PDF (with official MoSPI watermark)**, **Markdown**, **Word**, **JSON**, or **Plain Text**.
* **Proctored AI Assessment Engine:**
  * Anti-cheating watchdog detecting tab-switches (`visibilitychange`), window blurs, and devtools access.
  * Speed points conversion awarding remaining seconds on correct answers directly into Elo ratings.
  * Multi-format official **Academic Transcript Marksheets (PDF/PNG/JPG)** with letter grades ($O, A+, A, B+$) and MoSPI seals.
  * Automated **Quarterly WhatsApp & Email Performance Dispatches**.
* **Skill Gap Radar & Mistake Ingestion:**
  * Auto-captures every missed question during tests into an interactive review matrix.
  * **"Why?" Historical Audit Log:** In-depth comparison of officer choices versus correct official statistical standards.
  * **AI Preparation Roadmaps:** Targeted review guides and 1-click topic mastery workflows.
* **Official MoSPI Officer Cadre Dossier:**
  * Designed to replicate official Central Cadre Records: 136x136px avatar with saffron shadows, verified SSS cadre badge, service records, and competency pill cards.
  * 10 animated banner presets + custom 5MB upload engine.
  * Full-paragraph pop-up editor with character counts and unsaved data protection.
  * Connected social and professional verification links (LinkedIn, GitHub, iGOT, Portfolio).

## 💻 Local Development Setup

### Prerequisites
* **Python 3.10+**
* **Google Gemini API Key** (Obtained from [Google AI Studio](https://aistudio.google.com/))
* Modern Web Browser (Chrome, Edge, Firefox, Safari)

### 1. Clone the Repository
```bash
git clone https://github.com/suyashx1/nirdesha.git
cd nirdesha
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
SERVER_PORT=8000
DATABASE_URL=your_supabase_postgres_url_optional
```

### 3. Option A: Run High-Performance Unified Server (Recommended)
Nirdesha features a zero-dependency local daemon supporting full static serving and SSE streaming:
```bash
python server.py
```
Open **`http://localhost:8000`** in your browser.

### 4. Option B: Run FastAPI Microservice Backend
```bash
python -m venv venv
```
